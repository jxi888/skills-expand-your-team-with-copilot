# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities on WhatsApp, Facebook, or X, or copy a direct link without logging in

Shared links highlight the selected activity when opened. Sharing includes only the
activity name, schedule, and link, never participant details. If automatic copying
is unavailable, a selectable link is shown for manual copying.
